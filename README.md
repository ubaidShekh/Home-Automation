# AI-Powered Smart Home Automation System

An advanced IoT-based Smart Home Automation System built using React Native, Firebase, ESP8266, AI APIs, and real-time automation technologies.

This project combines home automation, AI interaction, weather intelligence, radar tracking, and smart device management into a single mobile application.

---

# Overview

This system allows users to monitor and control household electronic devices remotely using a mobile application.

The application supports:

- Real-time room-wise device control
- AI-powered chatbot interaction
- Weather-based automation
- Radar tracking integration
- Solar panel monitoring
- Robot control system
- Smart appliance automation

The goal of this project is to create an intelligent, scalable, and interactive smart home ecosystem.

---

# Key Features

## Room-Wise Smart Home Control

Users can control devices room-by-room.

Supported device controls include:

- Lights ON/OFF
- Fan ON/OFF
- Cooler Control
- AC Temperature Control
- TV Remote Control
- AC Remote Control
- Smart Door Control
- Smart Window Control

---

# AI Chatbot Integration

Integrated AI chatbot powered using Hugging Face APIs.

Capabilities:

- Normal conversations
- Smart home commands
- Weather information
- Automation requests

Example Commands:

```txt
Turn off the bedroom lights
Close the main door
What is the weather outside?
Turn on drying system
```

The chatbot can directly interact with home devices and automation workflows.

---

# Weather-Based Automation

Integrated weather APIs allow the system to automatically respond to environmental conditions.

Automation examples:

- Automatic window control during rain
- Automatic drying system ON/OFF
- Weather-aware door control
- Climate-based room automation

---

using external radar APIs.
